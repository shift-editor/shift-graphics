---
title: Create or open a font
description: Start a new font, or open the UFO, Designspace, Glyphs, and TrueType files you already have.
---

Shift edits fonts in its own `.shift` format. It can open other source formats and convert them to `.shift`.

In the shortcuts below, <kbd>Cmd</kbd> is the macOS key. On Windows and Linux, use <kbd>Ctrl</kbd> instead.

## Create a new font

Choose **File ▸ New Font** (<kbd>Cmd</kbd>+<kbd>N</kbd>), or click **New Font** in the launcher. Shift opens an empty font in a new window, ready to edit.

The font has no file yet. The first time you save, Shift asks where to put it. See [Save and reopen your work](/docs/files/save-and-reopen).

## Open an existing font

Choose **File ▸ Open…** (<kbd>Cmd</kbd>+<kbd>O</kbd>), or click **Open Font…** in the launcher. To reopen a font you used recently, choose **File ▸ Open Recent**, or pick it from the **Recent** list in the launcher.

| Format | Extension | What you can do |
| --- | --- | --- |
| Shift | `.shift` | Edit |
| Unified Font Object | `.ufo` | Preview, then save as Shift to edit |
| Designspace | `.designspace` | Preview, then save as Shift to edit |
| Glyphs | `.glyphs`, `.glyphspackage` | Preview, then save as Shift to edit |
| OpenType / TrueType | `.otf`, `.ttf` | View only |

## Convert a UFO, Designspace, or Glyphs source

Shift opens UFO, Designspace, and Glyphs sources as a read-only preview. You can look at every glyph, but the Pen and shape tools are turned off.

<Steps>
<Step>
Open the source file. A notice says **Save as Shift to edit**.
</Step>
<Step>
Click **Save as Shift…** and choose where to save the new `.shift` file. **File ▸ Save** and **File ▸ Save As...** do the same in a preview.
</Step>
<Step>
Shift opens the new `.shift` file, and you can edit it.
</Step>
</Steps>

Your original file is left untouched. Shift can’t write changes back to UFO, Designspace, or Glyphs yet.

<Callout type="warn" title="Conversion isn’t lossless yet">
  Some source-format features may be dropped or approximated. Compare the converted font with the original before relying on it, and keep the original.
</Callout>

## OpenType and TrueType fonts

Compiled `.otf` and `.ttf` fonts open view-only, and Shift can’t convert them to an editable font. Use them to inspect outlines or to compare with your own exports.
