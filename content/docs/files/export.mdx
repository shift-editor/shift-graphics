---
title: Export a font
description: Export a TrueType font from Shift so you can install it and test it in other apps.
---

Export a font to install it on your computer or try it in other apps. Shift 0.1.1 exports TrueType (`.ttf`) only.

<Steps>
<Step>
Open the `.shift` font you want to export. Export isn’t available for previews of UFO, Designspace, Glyphs, or compiled fonts. [Save the source as Shift](/docs/get-started/create-or-open-a-font#convert-a-ufo-designspace-or-glyphs-source) first.
</Step>
<Step>
Choose **File ▸ Export ▸ TrueType (.ttf)…**.
</Step>
<Step>
Choose a name and location, then click **Save**.
</Step>
</Steps>

Exporting writes a new font file. Your `.shift` file stays as it was, and so does its saved or unsaved state.

If something goes wrong, Shift says **We couldn’t export this font.** [Report the problem](/docs/help/report-a-problem) and attach the `.shift` file if you can share it.

## Limits

- Export has no options yet.
- OpenType CFF (`.otf`) and web fonts (WOFF, WOFF2) aren’t available yet.
- Shift has no spacing or kerning tools yet, so check your exported font’s metrics before you use it in a project.
