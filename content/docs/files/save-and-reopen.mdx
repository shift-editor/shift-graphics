---
title: Save and reopen your work
description: Save fonts as .shift files, and recover changes if Shift closes unexpectedly.
---

Shift saves fonts as `.shift` files. A `.shift` file holds the whole font in one file, so you can move, copy, and back it up like any other document.

In the shortcuts below, <kbd>Cmd</kbd> is the macOS key. On Windows and Linux, use <kbd>Ctrl</kbd> instead.

## Save

Choose **File ▸ Save** (<kbd>Cmd</kbd>+<kbd>S</kbd>). The first time you save a new font, Shift asks where to put it.

To save a copy under a new name or location, choose **File ▸ Save As...** (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd>).

If you opened a UFO, Designspace, or Glyphs source, both commands save it as a new `.shift` file and leave the original as it was. See [Create or open a font](/docs/get-started/create-or-open-a-font#convert-a-ufo-designspace-or-glyphs-source).

## Close with unsaved changes

Shift doesn’t save automatically. If you close a font with unsaved changes, Shift asks whether to save first. Choose **Save**, **Don’t save**, or **Cancel**.

## Recover after a crash

If Shift quits unexpectedly, it restores fonts that had unsaved changes the next time it starts. Review them and save.

<Callout type="warn" title="Keep backups">
  Shift is in alpha. Keep backup copies of fonts you care about, and save often.
</Callout>

## Reopen a font

- Pick it from the **Recent** list in the launcher, or choose **File ▸ Open Recent**.
- To clear that list, choose **File ▸ Open Recent ▸ Clear Menu**.
- If a recent font has been moved, choose **Locate…** from its **More actions** menu in the launcher to find it again.
